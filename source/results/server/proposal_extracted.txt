Training Data Thresholds for Cost Effective Korean Sentiment Analysis
Topic proposal  •  Movie reviews, product reviews, and game reviews
This project identifies when neural sequence models provide enough improvement over TF-IDF baselines to justify their additional computational cost on Korean review classification.
1 Research question
For each Korean review dataset, what is the minimum training size among 500, 1,000, 2,000, 4,000, and 8,000 reviews at which the best neural sequence model exceeds the best TF-IDF baseline by at least 1 macro-F1 point? At that threshold, does the neural model remain competitive in training time, inference latency, and memory use?
2 Why this question is interesting
A small team must decide whether to label more reviews or use a more complex model. Prior work shows that the preferred text classifier can change with data scale and efficiency requirements [1-4]. By estimating a clear crossover threshold on three Korean review domains, this project turns model comparison into a practical data-collection and deployment decision.

4 Techniques to use
The primary comparison is between two method families: TF-IDF classifiers and neural sequence classifiers. Four ML and five neural implementations provide candidates for finding the best pipeline within each family.
Method
Role and reason for inclusion
TF-IDF + Logistic Regression
ML: a linear classifier that tests whether weighted lexical cues are sufficient.
TF-IDF + linear SVM
ML: a margin-based linear comparator using the same features as Logistic Regression.
TF-IDF + Random Forest [8]
ML: an ensemble of randomized decision trees that tests nonlinear combinations of lexical features.
TF-IDF + XGBoost [9]
ML: boosted decision trees that complement Random Forest with a different ensemble strategy.
Average embeddings + MLP
Neural: a simple baseline inspired by deep averaging networks [2], with embeddings learned from scratch.
Embeddings + LSTM
DL: a gated recurrent backbone that models token order and sequential context.
Embeddings + GRU
DL: a second gated recurrent design for comparison with LSTM.
Small Transformer encoder
DL: self-attention with positional information for contextual token interactions.
Small Mamba classifier
DL: a selective state space backbone offering another approach to sequence modeling.
All methods use the same cleaned reviews and split IDs. Fit tokenization, vocabulary, TF-IDF, and other data-dependent transformations only on the current training subset. The four ML methods share token unigram/bigram TF-IDF features with L2 normalization and at most 10,000 features.
The neural methods share a training-only vocabulary, embedding size, and sequence limit, with embeddings learned from scratch. Match their non-embedding parameter budgets approximately and report actual counts. ML-versus-DL results compare complete pipelines because their representations differ.
Fairness comes from identical data, validation rules, and tuning opportunities. Report computational cost separately, and pilot Random Forest, XGBoost, and Mamba before freezing versions and resource limits.
Experimental protocol
Use nested, stratified training subsets of 500, 1,000, 2,000, 4,000, and 8,000 reviews. Each method receives identical review IDs for every dataset, size, and seed; validation and test sets stay fixed.
At 2,000 reviews, evaluate 10 predefined configurations per method and dataset using one tuning seed and validation macro-F1. Search regularization for linear models; tree structure and sampling for Random Forest; depth, learning rate, and rounds for XGBoost; and learning rate, dropout, and width for neural methods.
Freeze the selected configuration across training sizes within each dataset. Use fixed neural training rules and validation-based checkpoint selection. Freeze XGBoost rounds after tuning. Report tuning time because equal trial counts can require different computation.
Repeat every final condition with three predefined seeds. This gives 3 datasets × 9 methods × 5 sizes × 3 seeds = 405 final fits, plus 270 tuning fits. Report mean ± standard deviation; three seeds measure variability but do not establish statistical significance.
Evaluate frozen pipelines once on untouched test sets. Compare rankings within each domain and then their consistency across domains. Pretrained models and cross-domain transfer are outside the study.
Use one machine with fixed CPU thread limits and documented CPU/GPU assignments. Report end-to-end and classifier-only time, peak host RAM, GPU memory when applicable, serialized size, neural parameter counts, and tree/node counts.
5 Expected output
The Week 13 submission will include presentation slides, documented source code, five result tables, four figures, and an interactive demo comparing nine methods across three datasets.
Evaluation metrics
Macro-F1 is the primary metric; accuracy, macro-precision, and macro-recall are secondary. Report mean ± standard deviation and confusion matrices. The macro-F1 gain between adjacent data sizes will measure the value of additional labels.
Report fit and tuning time, serialized size, peak host/GPU memory, and batch-1 inference latency after warm-up. Measure both classifier-only and end-to-end latency, and document hardware, thread count, precision, and device.
Conclusions supported by the experiments
The primary conclusion will be the crossover threshold for each dataset: the smallest tested training size where the best neural model exceeds the best TF-IDF model by at least 1 macro-F1 point. If no tested size reaches that margin, the result will be reported as no observed crossover up to 8,000 reviews. At each crossover, cost measurements will determine whether the neural model is Pareto-efficient. Secondary analyses will describe saturation, cross-domain consistency, and difficult classes. Conclusions will be limited to the tested datasets, model families, and protocol.
